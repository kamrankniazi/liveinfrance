Variables clés
  • CODGEO : code INSEE commune à 5 chiffres (clé de jointure entre toutes les sources).
  • STAT_GSEC : catégorie socio-professionnelle. "13_23" = cadres et professions intellectuelles supérieures.
  • IMMI : 1 = immigré, 2 = non-immigré.
  • SEXE : filtré sur hommes (SEXE = 1) pour éviter le double comptage.
  • IPS (Indice de Position Sociale) : mesure le contexte socioéconomique des familles d’élèves. Plage ≈ 36–156. Valeur élevée = milieu plus favorisé.
Construction de l’indice composite

Calculé pour chaque paire commune × catégorie socio-professionnelle, en se limitant aux hommes immigrés. Communes de moins de 200 habitants exclues.

  1. Écart d’intégration : part_immi_gsec − part_gsec — différence entre la part d’une catégorie parmi les immigrés et dans la population totale. Un faible écart indique une bonne intégration.
  2. Part du groupe social : part de la catégorie dans la population totale de la commune.
  3. Part des immigrés : proportion d’immigrés dans la commune.
  4. IPS moyen : IPS moyen des écoles de la commune, année scolaire 2022–2023. Communes sans données scolaires : indice composite = NA.
Normalisation min-max

Chaque composante est normalisée entre 0 et 1 au sein de chaque groupe STAT_GSEC × Département :

Indice = (valeur − min) / (max − min)
Indice composite (produit des quatre indices)
Index = Idx_intégration × Idx_groupe × Idx_immigrés × Idx_IPS

Le produit garantit qu’une commune doit scorer haut sur toutes les dimensions pour atteindre un indice élevé.
